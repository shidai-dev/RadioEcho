# Radio Echo v0.1.19

## 更新内容

- **呼号通联历史自动查询**：在 CW / 语音中输入对方呼号，自动显示历史通联次数，查看曾用波段、模式和通联时间。
- 改善大量日志的加载，修复日志搜索时闪退。

## Highlights

- **Automatic callsign history:** Enter a DX callsign in CW / Voice to see past QSO counts and review previous bands, modes and contact times.
- Improved loading of large logs and fixed a crash when searching logs.

测试版：CW 实时输入、部分设备及手机版布局仍需验证；大量 LoTW 同步仍可能占用较高内存。

Preview: live CW text, some radio paths and phone layouts still need validation; large LoTW sync can still use substantial memory.
