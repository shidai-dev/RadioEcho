# Radio Echo 隐私政策

**版本：2026.08.08-binary-preview.2**

**生效日期：2026 年 8 月 8 日**

**个人开发维护者：BI1RRE**
**隐私联系邮箱：BI1RRE@163.com**

## 1. 处理者与基本原则

Radio Echo 不设应用账户，不建立自有云端日志库。由 BI1RRE 作为公开联系的个人开发维护者。

应用遵循本地优先、目的明确、最小必要和用户主动触发原则。除用户主动通过邮件或 Issue 提交反馈，以及用户主动使用联网服务外，通联日志、证书、音频和设备配置不发送给开发者。

## 2. 本机处理的数据

| 数据类别 | 用途 | 默认处理位置 |
| --- | --- | --- |
| 呼号、梅登网格、QTH、通联偏好、QRZ 结果 | CW/FT8 明文、位置、距离、地图和日志 | 本机设置或内存 |
| ADIF/QSO 日志、LoTW 状态和上传队列 | 日志管理、导入导出、签名和用户确认的上传 | 本机应用文件 |
| 电台型号、蓝牙/USB/WLAN 目标、CI-V/CAT 参数和凭据 | 设备发现、连接和控制 | 本机设置；密码使用安全存储 |
| 接收音频、频谱帧、FT8 解码和发射音频 | 本机接收、解码、显示和用户发起的发射 | 默认仅内存临时处理 |
| 地图 API Key、LoTW/QRZ/Telnet 配置和 P12 证书 | 用户主动启用相应服务 | 本机设置、安全存储或应用文件 |

上述数据不用于广告、用户画像或出售个人信息。

## 3. 系统权限

- **蓝牙、附近设备和兼容系统上的位置权限**：扫描并连接用户选择的蓝牙电台；
- **麦克风和音频设置权限**：使用内置麦克风测试 FT8 接收，或处理用户启用的音频路由；
- **互联网和网络状态**：连接 Icom WLAN、电台局域网及用户启用的第三方服务；
- **系统文件选择器**：导入或导出 ADIF、P12/TQ5、配置备份及诊断文件。

拒绝可选权限不会阻止查看本地日志和不依赖该权限的页面，但对应功能将不可用。

## 4. 第三方与可能的境外传输

用户主动配置或点击相关功能时，应用会从设备直接连接第三方。网络连接通常会向服务方暴露 IP 地址、请求时间和必要参数。部分服务位于中国大陆境外。

| 接收方类别 | 可能发送的数据 | 触发方式 |
| --- | --- | --- |
| [ARRL LoTW/TrustedQSL](https://www.arrl.org/lotw)（美国） | 用户核对并确认上传的签名通联日志、登录请求 | 手动确认上传或主动同步 |
| [QRZ LLC](https://www.qrz.com/page/xml_data.html)（美国） | 账号登录信息、待查询呼号、官方 XML 查询请求 | 用户配置后自动或手动查询 |
| [国家地理信息公共服务平台天地图](https://www.tianditu.gov.cn/)（中国大陆） | API Key、地图瓦片范围、网络请求信息 | 打开启用地图的页面 |
| Telnet/DX Cluster、PSK Reporter、WSPR、RBN | 呼号、波段、时间窗口和公开传播查询条件 | 用户连接或刷新 |
| 用户配置的电台或服务器 | 控制命令、连接凭据及链路所需音频 | 用户发起设备连接 |

QRZ 呼号查询仅使用官方 XML Callbook Data Service，不抓取 QRZ 个人资料网页。天地图画面显示底图来源及 `GS(2025)1508` 审图号。

应用不会把一种服务的密码交给另一种服务，也不会把 P12 私钥上传给开发者。用户可通过关闭相应功能、删除其配置或卸载应用停止后续请求；第三方已经接收的数据适用其自身政策和权利请求程序。QRZ 权利请求和支持入口为 [QRZ Support Center](https://ssl.qrz.com/support)，ARRL 联系与隐私信息见 [ARRL Privacy Policy](https://www.arrl.org/privacy-policy)。

## 5. 保存、安全与配置备份

本地设置、日志和证书通常保存至用户删除、覆盖、清除应用数据或卸载应用。内存音频和频谱帧不默认形成永久录音；仅在用户主动导出诊断音频时生成文件。

密码类凭据使用系统安全存储。配置备份可包含用户选择导出的账号、密码和 API Key；完整备份中的敏感配置可能以可读取形式写入所选文件，应仅保存到可信或加密位置。P12 文件和证书密码不随配置备份导出。

任何本地或联网安全措施都不能保证绝对安全。用户应保护设备锁屏、P12 证书、备份文件和第三方账户。

## 6. 用户权利与删除

用户可在设置中查看或修改台站、设备和第三方配置；可在日志页面查询、编辑、删除和导出本地日志；可撤回协议同意、清除应用数据或卸载应用。删除本地记录不会删除第三方已经接收的数据。

有关个人信息处理规则的查询、复制、更正、删除、限制处理和撤回同意请求，请联系 BI1RRE@163.com。依法必须保留或技术上无法立即删除时，将停止除保存和安全保护外的处理。

## 7. 未成年人、变更与联系

本应用不面向不满十四周岁的未成年人提供。未成年人不得借助本应用绕过业余无线电操作资格、台站执照或监护要求。

本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络数据安全管理条例》等规则编写。发生实质变更时将更新版本并重新请求确认。本政策不构成针对具体个案的法律意见。
