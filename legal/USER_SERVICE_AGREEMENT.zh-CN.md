# Radio Echo 用户服务协议

**版本：2026.08.08-binary-preview.2**

## 1. 协议适用与开发者身份

Radio Echo 是由 BI1RRE 以个人爱好者身份独立开发维护的业余无线电辅助软件，不设公司运营主体、应用内账户或自有云端日志平台。本协议适用于当前 GitHub Release 提供的 Android 二进制 APK，以及其中的 CW、FT8、设备控制、日志、地图和联网服务功能。

本应用不授予业余无线电操作资格、台站执照、呼号或行政许可，也不替代电台说明书、主管部门规则和实际操作人的判断。

## 2. 免费二进制发行

当前 GitHub Release 提供免费测试 APK，不启用试用倒计时，不要求设备码或授权码。免费使用不表示 Radio Echo 自有代码、界面、图形、名称或文档按开源许可证发布，也不转移相关知识产权。

在遵守本协议的前提下，用户获得个人、有限、非独占、不可转让的应用使用权。软件及其自有界面、代码、图形和文档的所有权不会因下载安装而转移。

适用开源许可证、法律允许的研究、兼容性分析或强制性权利不受本条限制。除此之外，用户不得：

- 未经许可修改、注入、重打包、冒名发布或出售本应用；

## 4. 用户资格与发射责任

用户在启用 CAT、PTT、CW、FT8 发射、自动 CQ 或自动应答前，应确认具有所在地法律要求的操作技术能力、合法可用的业余无线电台执照和呼号，并遵守执照及主管部门规定的频率、模式、功率、地点和设备要求。

自动化功能只是操作辅助。用户必须保持必要监督、确认电台实际状态，并对呼号、发射内容、频率、功率、天线、日志和第三方提交内容负责。

## 5. 禁止行为与安全底线

用户不得利用本应用实施以下行为：

- 冒用、伪造、出租、出借或擅自编制呼号、执照或台站身份；
- 超出许可范围发射、故意干扰或在发现有害干扰后继续发射；
- 发布法律法规禁止传播的信息，或将业余无线电用于谋取商业利益等超出业余业务属性的通信；
- 绕过电台、第三方服务或本应用的访问控制和授权机制。

出现有害干扰、错误频率或模式、异常 ALC/驻波、PTT 失控、设备断连、天线异常或无法确认合规时，用户应立即在应用或电台端停止发射。

## 6. 日志与第三方服务

应用可按用户操作接入 LoTW/TrustedQSL、QRZ、天地图、Telnet 集群、PSK Reporter、WSPR、Reverse Beacon Network 和用户配置的电台服务。第三方独立提供服务，并适用其各自条款、隐私规则、可用性和地区限制。

LoTW 日志只允许用户手动确认上传。用户应在提交前核对呼号、日期、时间、频率、模式和报告。第三方一旦接收，删除、更正和争议处理应遵守第三方规则。用户应自行定期导出和备份本地 ADIF。

## 7. 更新、支持与停止使用

应用更新可能修复缺陷、调整设备兼容性或改变功能。涉及个人信息处理或发射安全的重大变更，将更新协议版本并在继续使用前重新请求确认。

产品支持可通过 BI1RRE@163.com 联系。用户可以停止使用、撤回协议同意或卸载应用；撤回同意不会自动删除日志、证书和第三方已经接收的数据。

## 8. 免责声明与责任边界

应用按现状提供，不保证无错误、不间断、适用于所有设备、网络、电台固件或通联环境。用户应先在低功率、可控环境中验证连接、频率、模式、音频、PTT、ALC、驻波和日志。

任何免责或责任限制仅在法律允许范围内有效，不排除开发者因故意、重大过失或法律明确不得免责事项应承担的责任，也不排除用户依法享有的主要权利。

本协议适用中华人民共和国法律。争议应先通过联系邮箱协商；协商不成的，依法向有管辖权的人民法院解决。
